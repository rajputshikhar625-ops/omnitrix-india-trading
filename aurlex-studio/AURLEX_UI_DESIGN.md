# Aurlex Studio UI Design System

- Base: cinematic near-black #050712
- Typography: Inter + Space Grotesk
- IDEA: violet/cyan
- RESEARCH: cyan/green
- FORMAT: amber/orange
- STORY: pink/violet
- ANIMATION: red/amber
