# Aurlex Studio Pro — Production UI

Aurlex Studio is an autonomous animation-video production workspace.

## Workflow
1. IDEA
2. RESEARCH
3. FORMAT
4. STORY
5. ANIMATION
6. VERIFY
7. PUBLISH

## Publishing assets
The Publish Studio generates:
- YouTube thumbnail (1280x720)
- Official poster/key art
- YouTube teaser (16:9)
- Instagram/Reels teaser (9:16)
- Master MP4

## UI
The local Streamlit UI now uses a cinematic dark workspace with page-specific accent colors, a workflow stepper, responsive cards, glass panels, and a locally cached Unsplash background.
